Click "Apply" on a brand's program page and you often land somewhere else: a platform the brand uses to run its program. That is normal. This page explains the kinds you will meet. Each card in the directory names the platform when the brand's page links to one.

## Creator platforms built into the store

**Shopify Collabs** is Shopify's own tool for brands that sell on Shopify. You create a free creator account, apply to a brand, and if accepted you may get product gifts, a discount code to share, and commission on sales. One account works across every brand that uses it. See [brands that take applications through Shopify Collabs]({base}/apply/shopify-collabs/).

## Affiliate apps a store installs

**UpPromote, GoAffPro, BixGrow, Refersion, Social Snowball, Affiliatly** and similar apps add an affiliate program to an online store. You register on that brand's affiliate page, and you get a tracked link, a code and a dashboard that shows clicks, sales and what you are owed. You usually need a separate registration for each brand.

## Affiliate networks

**impact.com, Awin, CJ, Rakuten Advertising** and others are marketplaces that sit between many brands and many publishers. You join the network once, then apply to each brand inside it. Networks handle tracking and payment, and they suit people with a website, a newsletter or a large audience.

## Hosted forms

Many smaller brands just link a **Google Form, Typeform, Tally or Jotform**. There is no account. You answer the questions, and the brand replies by email if it wants to go ahead.

## A sign-up portal on the brand's own site

Some brands run the program on an address of their own, such as `ambassadors.example.com`. It is usually one of the apps above with the brand's name on it.

## Before you create an account anywhere

- **Check you got there from the brand's own website.** The safest path to any platform is the link on the brand's program page.
- **Read what you are agreeing to.** Commission rate, cookie window, payout minimum, payout method, and whether the brand can change the terms.
- **Note how you are paid.** Some platforms pay by PayPal or bank transfer, some pay store credit.
- **Use a password you do not use elsewhere.**
- **Remember the disclosure rules.** A tracked link or code is a material connection. [Disclose it]({base}/guides/disclose-gifted-products-and-affiliate-links/).

This directory is not affiliated with any of these platforms. Platform names are used only to describe where a brand's own page sends applicants.
